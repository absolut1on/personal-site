Motivation

Curious first. Simple always.

Years ago, hunting for a Skyrim modding tool, I landed on GitHub and spent hours reading someone else's code. The idea that people just share how things work, openly, hooked me for good. I'm still that curious: I benchmark things nobody asked me to, reverse-engineer tools with thin docs, and keep code simple so the next person doesn't need me to explain it. Next on the list: kernel development.

  1. If it's hard to explain, it's too complicated.
  2. Benchmark it before you believe it.
  3. Own it end to end, from the first design to the last bug report.
